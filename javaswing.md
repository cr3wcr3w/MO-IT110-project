Top-Level Containers

JWindow → undecorated window

  JTextField → single-line input
  JPasswordField → password input
  JTextArea → multi-line text
  JTextPane → styled text
  JEditorPane → HTML/text editor
Buttons
  JButton → clickable button

  JCheckBox → checkbox
  JRadioButton → radio button

  JComboBox → dropdown
  JList → selectable list

  JSlider → slider
  JColorChooser → color picker
  JFileChooser → file picker

  JPopupMenu
