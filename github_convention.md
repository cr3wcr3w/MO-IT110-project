# Git Branching & Commit Convention

## Commit Message Format

Use the following format for commits:

```bash
feat: <message>
fix: <message>
chore: <message>
refactor: <message>
```

### Examples

```bash
feat: add authentication flow
fix: resolve login validation bug
chore: update project dependencies
refactor: simplify auth controller logic
```

---

## Branch Naming Format

Use this format for branch names:

```bash
<name>/feat-<name-of-the-changes>
<name>/fix-<name-of-the-changes>
<name>/chore-<name-of-the-changes>
<name>/refactor-<name-of-the-changes>
```

### Example

```bash
jk/feat-add-auth-flow
```

---

Please follow these conventions para organized and madaling i-track yung changes natin. 👍
